TCP-сокеты: простой сервер и клиент
Дисциплина: Сетевое программирование (язык Python)
Цель занятия: научиться создавать TCP-сокеты в Python и написать простую пару программ «сервер — клиент», обменивающихся сообщениями.

Контрольные вопросы
    • Что такое сокет? Какие параметры задаются при его создании?
    Сокет — это программный интерфейс для обмена данными по сети. Он связан с парой «IP-адрес + порт» и позволяет программе отправлять и принимать данные так же, как при работе с файлом.
    При создании сокета в Python указывают два параметра:
    1) socket.AF_INET — используется адресация IPv4;
    2)socket.SOCK_STREAM — используется протокол TCP (потоковая передача с установкой соединения).
    • В каком порядке сервер вызывает socket, bind, listen и accept?
    1)socket
    2)bind
    3)listen
    4)accept
    • Что возвращает метод accept()?
    возвращает новый сокет соединения и адрес клиента
    • Почему перед отправкой строку нужно кодировать?
    по сети передаются байты, а не строки
    • Почему сервер нужно запускать раньше клиента?
    Сервер открывает сетевой порт и переходит в режим прослушивания. Если запустить клиент раньше, он попытается отправить запрос, но адрес окажется недоступным.
